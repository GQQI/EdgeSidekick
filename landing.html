Capabilities

一个工作台，一支智能体小队

打开本机文件夹，在浏览器里对话。主智能体编排、子智能体协作，搜索与编辑文件——变更需你确认。

01

多智能体协作

主智能体拆解任务，子智能体并行委派。重活用强模型、杂活用小模型，主 / 子 / 压缩模型分档配置。

02

浏览器沙盒

CDP / Playwright 驱动 Chromium：预览本地站、Select Mode 点选 DOM 发给 Agent，browser_* 工具化验收页面。

03

审批门安全边界

写入 / 删除 / Shell / 记忆变更先征求确认；本机令牌认证，API Key 本机密钥加密存储，默认仅绑定 127.0.0.1。

04

Skills 即插即用

往 src/skills/ 丢一个目录就是技能，/skill 一键调用，按需加载不占 prompt。

05

为省 Token 而设计

上下文将满自动压缩（有轮次上限），Skills 按需调用而非每轮塞长流程——同样干活，计费轻一截。

06

文件名与内容双搜索、点击跳行；流式对话、详情面板一体；编辑可回退，历史分页可追溯。

Built for Forking

为二开而设计

Python + Vite 分层清楚：API、智能体、工具、Skills、Memory 各自独立。加一个 Skill 或注册一条工具，就能做出自己的私有版，不用硬啃黑盒。

# 注册一条自己的工具
@tool("my_tool")
def my_tool(query: str):
    return search(query)
# 丢一个目录就是技能
src/skills/my-skill/SKILL.md
01

分层运行时

src/metateam 内 core / runtime / services / api 四层：智能体循环、工具注册、审批门、SSE 事件流各司其职，改一层不牵全身。

02

工具即插件

文件、Shell、Git、浏览器、委派、记忆均为独立工具模块，经统一 registry 注册与参数校验，新增工具只需一个文件。

03

三平台打包链

Windows 离线 .exe、麒麟 / Linux .deb + AppImage、源码直跑，一条脚本出包，目标机无需预装 Python / Node。

04

数据在你这边

本机运行、自备 Key。历史、Memory、工作区文件全部落在你控制的磁盘上，内网 / 本机 Ollama 亦可全离线对话。
