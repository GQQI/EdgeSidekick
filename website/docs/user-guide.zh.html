EdgeSidekick 使用手册

本地多智能体 AI 工作台。本手册说明安装启动、工作台与会话版、对话、主题、Skills 与基础设置。

安装与启动 工作台 vs 会话版 对话协作 浅色 / 深色 Skills 基础设置

1. 安装与启动

源码运行（通用）

python -m pip install -r requirements.txt
python main.py

浏览器打开 http://127.0.0.1:8787。

桌面端

  • Windows：双击 start-desktop.bat，或使用打包好的安装包 / 便携 zip。
  • 麒麟 / Linux：使用 .deb / AppImage，或按 README 构建桌面端。
首次启动会要求选择工作区文件夹。历史、Memory 等数据保存在本地磁盘，默认不出境。

2. 工作台模式 vs 会话版

工作台（Workbench）

面向工程与任务：主智能体调度子智能体、文件编辑、Shell、浏览器沙箱、任务面板。适合写代码、改文档、跑命令。

会话版（Social / Session）

面向对话与多人协作感：会话列表、私聊式界面，同样可调用智能体能力。适合日常问答、持续话题跟进。

两者共用同一本地运行时与模型配置，可按场景切换。

3. 对话与多智能体

  • 在输入框发送消息；回复以流式（SSE）呈现。
  • 主智能体可调度子智能体协同；写文件、Shell、改 Memory 等通常需人类确认。
  • 支持附件、停止生成、编辑后重发；必要时可回滚相关文件变更。

4. 主题与语言

  • 浅色清爽：日间阅读与长时间编码。
  • 深色沉浸：夜间低刺激工作。
  • 界面支持中 / 英切换；官网与应用内可分别记忆偏好。

5. Skills 技能包

  • 将技能包放入 src/skills/（或租户 skills 目录）。
  • 对话中用 /skill 按需调用；工具按需加载，避免每轮塞入巨型 prompt。
  • 内置示例覆盖写作、调试、演示文稿等场景，可按需增删。

6. 基础设置

  • 模型：主模型 / 子智能体 / 压缩模型可分开配置；支持自备 API Key 或本地 Ollama。
  • 工作区：设置 → 选择本地文件夹；可切换最近工作区。
  • 浏览器沙箱：桌面端 BrowserView / Web Playwright；Select Mode 点选 DOM，智能体用 browser_* 工具操作页面。
  • Memory / 任务 / MCP：MEMORY.md 可追加或改写（需确认）；任务面板跟踪进度；MCP 接入外部工具。
API Key 与令牌只保存在本机配置中。分发演示包前请清空 src/data 中的个人令牌与密钥。

更多技术细节见仓库根目录 README.md。
