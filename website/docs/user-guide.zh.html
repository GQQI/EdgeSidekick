EdgeSidekick 使用手册

本地多智能体 AI 工作台。本手册说明如何打包 Windows 桌面端 exe、配置大模型，以及工作台、对话、主题、Skills 与基础设置。

打包成 exe 配置大模型 工作台 vs 会话版 对话协作 浅色 / 深色 Skills 基础设置

1. 打包成 exe（Windows）

在能联网的 Windows x64 开发机上打一次包，得到安装程序；拷到目标机器后双击安装即可，目标机不需要预先安装 Python 或 Node.js。

环境要求

  • Windows x64
  • Node.js 18+
  • 本机可调用的 Python（脚本会用它准备嵌入式运行时；也可用项目内 .venv）
  • 能访问 npm / pip 镜像（脚本默认华为云、npmmirror、清华 PyPI）

执行打包命令

在仓库根目录打开 PowerShell 或 CMD，运行：

.\scripts\build-windows.bat

等价写法：

powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1

可选参数

参数作用
-SkipRuntime复用已有 packaging/windows/payload/python
-SkipUi复用已有 ui/dist
-SkipPlaywright不打入 Chromium（体积更小，Agent 浏览器工具不可用）
-Force强制重下 Python 运行时

示例（跳过 Chromium、复用 UI）：

.\scripts\build-windows.bat -SkipPlaywright -SkipUi

产物与安装

构建完成后，产物在 desktop/dist/：

  • EdgeSidekick-Setup-<version>-win-x64.exe — NSIS 安装程序（推荐）
  • EdgeSidekick-<version>-win-x64.zip — 解压即用的便携版
  1. 双击 Setup .exe 安装（默认装到当前用户目录，通常无需管理员）
  2. 从开始菜单或桌面快捷方式启动 EdgeSidekick
  3. 首次启动选择工作区文件夹
配置与会话默认写在 %APPDATA%\EdgeSidekick\。未签名时 Windows 可能提示 SmartScreen：选「更多信息」→「仍要运行」。

麒麟 / Linux（可选）

在 Linux 上可打包 .deb / AppImage / tar.gz：

bash scripts/build-kylin.sh

详见仓库 packaging/kylin/README.md。

2. 配置大模型

应用打开并选好工作区后，先配置模型才能正常对话：

  1. 打开 设置 → 模型
  2. 填写 API Base URL（OpenAI 兼容接口，或本地 Ollama 等）
  3. 填写 API Key（本地 Ollama 可按服务商说明留空或填占位）
  4. 选择 / 填写模型名称；如需省 Token，可为主模型、子智能体、压缩模型分别配置
  5. 保存后回到对话页，发送一条消息验证连通性
API Key 只保存在本机（安装版默认在 %APPDATA%\EdgeSidekick\）。历史、Memory 等数据默认不出境；对话仍需要能访问你配置的模型 API（公网、内网或本机均可）。

3. 工作台模式 vs 会话版

工作台（Workbench）

面向工程与任务：主智能体调度子智能体、文件编辑、Shell、浏览器沙箱、任务面板。适合写代码、改文档、跑命令。

会话版（Social / Session）

面向对话与多人协作感：会话列表、私聊式界面，同样可调用智能体能力。适合日常问答、持续话题跟进。

两者共用同一本地运行时与模型配置，可按场景切换。

4. 对话与多智能体

  • 在输入框发送消息；回复以流式（SSE）呈现。
  • 主智能体可调度子智能体协同；写文件、Shell、改 Memory 等通常需人类确认。
  • 支持附件、停止生成、编辑后重发；必要时可回滚相关文件变更。

5. 主题与语言

  • 浅色清爽：日间阅读与长时间编码。
  • 深色沉浸：夜间低刺激工作。
  • 界面支持中 / 英切换；官网与应用内可分别记忆偏好。

6. Skills 技能包

  • 将技能包放入 src/skills/（或租户 skills 目录）。
  • 对话中用 /skill 按需调用；工具按需加载，避免每轮塞入巨型 prompt。
  • 内置示例覆盖写作、调试、演示文稿等场景，可按需增删。

7. 基础设置

  • 工作区：设置 → 选择本地文件夹；可切换最近工作区。
  • 浏览器沙箱：桌面端 BrowserView / Web Playwright；Select Mode 点选 DOM，智能体用 browser_* 工具操作页面。
  • Memory / 任务 / MCP：MEMORY.md 可追加或改写（需确认）；任务面板跟踪进度；MCP 接入外部工具。
斜杠命令：/help · /new · /clear · /skills · /skill <名称> · /memory · /history · /browser · /stop

更多技术细节见仓库根目录 README.md 与 packaging/windows/README.md。
