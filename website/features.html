Features

功能

为真实工作流准备的能力清单。

CHAT

多智能体对话

主智能体调度子智能体，SSE 流式输出，变更需确认。

BROWSER

浏览器沙箱

桌面 BrowserView / Playwright；Select Mode 点选 DOM。

SKILLS

Skills · MCP

按需加载技能包与外部工具，不把巨型 prompt 塞进每一轮。

DESKTOP

桌面应用

Windows 安装包、麒麟/Linux deb/AppImage，或 start-desktop.bat。

MEMORY

记忆 · 任务

MEMORY.md 可追加/改写（需确认）；任务面板跟进进度。

THEME

浅色 / 深色

浅蓝白主视觉，一键深色；中英双语。

四步上手

01

打开工作区

选择本地文件夹，历史与 Memory 落在你控制的磁盘上。

02

配置模型

主模型 / 子智能体 / 压缩模型可分开设置，自备 API Key 或 Ollama。

03

对话与确认

写文件、Shell、记忆等变更先征求批准再执行。

04

扩展能力

Skills、浏览器沙箱、MCP 按需挂载。
