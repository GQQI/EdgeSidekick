Features

为真实工作流设计

对话、浏览器沙箱、Skills、桌面端、记忆与任务、浅色/深色——一块蓝白 AgentFrame 风格工作台全部齐备。

CHAT

多智能体对话

主智能体调度子智能体，SSE 流式输出，附件、停止、编辑重发与文件回滚一步到位。

BROWSER

浏览器沙箱

桌面 Electron BrowserView / Web Playwright；Select Mode 点选 DOM，Agent 用 browser_* 工具操作页面。

SKILLS

Skills 技能包

拖入 src/skills/，用 /skill 按需调用——工具按需加载，不把巨型 prompt 塞进每一轮。

DESKTOP

桌面应用

Windows 安装包、麒麟/Linux deb/AppImage，或 start-desktop.bat 一键拉起 Electron 工作台。

MCP

记忆 · 任务 · MCP

MEMORY.md 可追加/改写（需确认）；任务面板跟进进度；MCP 扩展把外部工具接到同一运行时。

THEME

浅色 / 深色

AgentFrame 蓝白浅色主视觉，一键切换深色；中英双语，适合日夜长时间工作。

How it works

四步上手

从打开文件夹到多智能体协作，不到一分钟。

01

打开工作区

选择本地文件夹，历史与 Memory 都落在你控制的磁盘上。

02

配置模型

主模型 / 子智能体 / 压缩模型可分开设置，自备 API Key 或接 Ollama。

03

对话与确认

写文件、Shell、记忆等变更动作先征求人类批准，再执行。

04

扩展能力

Skills、浏览器沙箱、MCP 工具按需挂载，fork 友好分层架构。

Interface

浅色清爽 · 深色沉浸

同一工作台，两种氛围。浅色清爽适合日间专注；深色沉浸适合夜间长时工作。

Demo

产品演示

一分钟看清核心能力：工作台、会话版、多智能体对话、浏览器沙箱、Skills 与本地桌面。
