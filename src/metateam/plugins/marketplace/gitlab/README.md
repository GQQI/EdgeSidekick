# GitLab 插件

适用于 gitlab.com 和自建 GitLab：查询项目、Issue 与合并请求，读取 MR 的改动做评审，读取仓库文件，并在你确认后创建 Issue 或发表评论。

## 配置

1. 在 GitLab「偏好设置 → 访问令牌」创建个人访问令牌（自建实例同理）。
   - 只读：勾选 `read_api`
   - 需要写入：勾选 `api`
2. 在「设置 → 插件」粘贴令牌；自建实例把「GitLab 地址」改成你的实例根地址。
3. 点「验证」确认可用。

`project` 参数既可以写 `group/sub/project` 路径，也可以写数字 id，还可以直接粘贴项目网址。
